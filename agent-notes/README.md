# agent-notes/

Hand-off notes written **by AI agents (and humans) for other agents and team members**.

`docs/` holds the frozen, contractual material (integration contracts). This folder is for the working
record: what a session did, why, what was decided, what is left to do, and how to reproduce it. Notes
here are not contracts and may go out of date; treat `docs/integration-contracts.md` and `AGENTS.md` as
authoritative when they disagree.

## Conventions

- **One file per task/session**, named `YYYY-MM-DD-<area>-<short-topic>.md`
  e.g. `2026-11-25-member5-qa-integration.md`.
- Start every note with a short **Summary** (3–6 bullets) and a **Status** line
  (`done` / `in progress` / `blocked`).
- Record **which files/folders were touched**, especially anything outside the author's own area.
- List **verification commands and their results** (test counts, coverage numbers).
- End with **Follow-ups** and **Open questions for the group**.
- Do not put secrets or credentials in notes.
